BRAINWAVE ORGANISM

2025 / Web-based interactive data visualisation

  • TECHNIQUES:
  • - p5.js, HTML, CSS, Python
  • - OpenNeuro EEG datasets
  • - Dynamic interaction design, data visualisation
  • - Valencia, Spain

Brainwave Organism is an interactive visualisation project based on EEG data and linguistic stimulation. It transforms abstract brainwave signals into a dynamic “biological body” that grows, pulses, and mutates in response to external information.

The project explores how different linguistic inputs such as English, American Sign Language, and fingerspelling produce distinct neural responses. Through particles, synaptic lines, semantic word bubbles, and environment-based growth conditions, the interface makes neural activity perceptible as a living visual ecosystem.

Designed as both an artistic interface and a sensory extension tool, the work proposes a pathway toward multisensory human-computer interaction through visual, tactile, and auditory channels.
