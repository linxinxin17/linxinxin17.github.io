BRAINWAVE ORGANISM

2025 / Visualización creativa de datos EEG e interfaz web interactiva / Valencia, España

  • DATOS Y DESARROLLO:
  • Fuente de datos: OpenNeuro ds005565 v1.0.3, conjunto de datos EEG-ERP Ver conjunto de datos original
  • Contexto del estudio: priming semántico entre inglés impreso, ASL y deletreo manual
  • Procesamiento y desarrollo: Python, p5.js, HTML y CSS
  • Sistema visual: seis entornos de crecimiento, movimiento de ondas cerebrales y matriz de participantes

Brainwave Organism toma como base la visualización de datos de ondas cerebrales y explora los cambios que se generan cuando el cerebro recibe información externa, como texto, lenguaje de señas estadounidense o deletreo manual.

El conjunto de datos procede del estudio OpenNeuro Neural Associations Between Fingerspelling, Print, and Signs, centrado en el priming semántico con lectores sordos. La secuencia Prime-Target-Probe presenta estímulos en inglés impreso, ASL o deletreo manual y registra la respuesta semántica. La interfaz trabaja con los campos onset, muestra y valor EEG; identifica visualmente los registros no disponibles y utiliza valores simulados solo para mantener la continuidad de la demostración.

Las señales se transforman en comportamientos orgánicos, como latidos, expansión celular, crecimiento de redes neuronales y flujo de partículas. Las partículas indican intensidad y densidad; las ondas y conexiones evocan sinapsis; las burbujas de palabras funcionan como unidades de transferencia de información. La matriz usa azul para participantes masculinos, magenta para femeninos, blanco para datos ausentes y amarillo para la selección activa.

Como proyecto de visualización creativa de datos, propone una vía para la práctica del arte multisensorial y para futuros sistemas de interacción multicanal entre visualización, tacto y sonido.
